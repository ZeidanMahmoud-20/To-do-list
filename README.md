# To-do-list

## Description

A simple to-do list web app that lets users add, view, complete, and delete tasks. Tasks are saved in the browser, so your list is still there the next time you open the page.

## Features

- Add a task with an optional due date.
- View all tasks in one list.
- Mark a task as done by clicking the circle next to it.
- Delete a task with the ✕ button.
- Clear all completed tasks at once.
- See how many tasks are left.
- Overdue tasks (past their due date and not done) are highlighted.
- Tasks are saved automatically using the browser's local storage, so they persist after a refresh.

## How it works

- `index.html` — the page structure: the add-task form and the task list.
- `css/app.css` — all styling, including the completed and overdue states.
- `js/app.js` — the app logic: adding, rendering, completing, deleting, and saving tasks to `localStorage`.

## Getting started

No build step or install needed.

1. Download or clone the repository.
2. Open `index.html` in your browser.
3. Type a task, optionally pick a due date, and click **Add task**.
